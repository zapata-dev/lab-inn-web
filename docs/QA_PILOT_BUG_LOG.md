# QA Pilot Bug Log (LAB-PROD-022)

Registro de bugs encontrados durante el QA end-to-end del piloto LAB.

---

## Severidades

| Nivel | Criterio | Impacto en piloto |
|-------|----------|------------------|
| **Crítico** | Fuga de datos entre usuarios, acceso no autorizado, corrupción de datos, login externo exitoso, crash no recuperable | **No-Go inmediato** |
| **Alto** | Flujo principal roto sin workaround (crear solicitud falla, notificación no llega, PDF roto) | No-Go salvo workaround documentado |
| **Medio** | Flujo funciona con fricción; workaround disponible | Go con restricción documentada |
| **Bajo** | Visual, copy incorrecto, mejora de UX, estado vacío confuso | Go sin restricción, backlog |

---

## Estado de bug

| Estado | Significado |
|--------|------------|
| `Abierto` | Reproducible, sin fix |
| `En revisión` | Siendo investigado |
| `Fix en progreso` | Ticket de fix creado |
| `Cerrado` | Fix desplegado y verificado |
| `No reproducible` | No se pudo reproducir |
| `Won't fix` | Aceptado como limitación conocida |
